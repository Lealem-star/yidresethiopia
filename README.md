# yidresethiopia

Digital reading site for the Amharic book **ተስፈኛ ወጣት** (የኔ ድርሻ).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Reader pages, table of contents, and public feedback live in the app. The PDF should stay at `public/books/yenederesha.pdf`.
